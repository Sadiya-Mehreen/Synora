# SYNORA

## One-liner
An AI that calls you to test what you actually remember.

## Target user
College students studying technical subjects.

## Problem
Students often mistake recognition for actual understanding.

## Solution
Synora uses conversational phone calls to force active recall,
evaluate explanations, detect misconceptions, and schedule
future reviews.

## MVP
1. Add topic
2. Generate recall question
3. CALL-E calls user
4. User answers
5. AI evaluates answer
6. Memory state updates
7. Next review scheduled

## Memory states
- Mastered
- Fading
- Forgotten
- Misconception
